# Arena Visualiser

I built an arena allocator and a visualiser for it using OpenGL and GLFW.

This was my first time using OpenGL, so the code probably isn't the prettiest, but it was a really fun project and a great way to learn some graphics programming.

## Cloning

I've attempted to include all dependencies as vendors, so ideally cloning recursively should be all you need to download and build the project

```bash
git clone --recursive git@github.com:Wyliemaster/Arena-visualiser.git
```

## Additional information

Although I've attempted to make it compatible for any machine, it was ultimately written on an Ubuntu Linux machine. So I can not guarantee that it will build on Windows
